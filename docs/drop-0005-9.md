## Harness rule

The existing binary remains:

```text
engine_stress::chaos4
```

Default invocation still produces the historical DROP 0004.9 report.

DROP 0005 adds an explicit extension mode:

```bash
cargo run -q -p engine_stress --bin chaos4 -- --drop5 <report.json>
```

The DROP-5 run executes every old DROP-4 abuse case first, then the new
mechanics/participation cases.

Both the old and new isolation tests follow the same hard invariant:

```text
pristine live target
        ↓
baseline manifest/digest
        ↓
disposable copy
        ↓
destructive abuse only in the copy
        ↓
verify live target byte-identical
        ↓
tear down disposable copy
```

The live target is never the chaos sandbox.

the whole structure.

### Capacity across a region boundary

A steel load path crosses a residency-region seam.

With complete residency:


With the adjacent region unknown:


Unknown remains unknown. A missing region is never treated as empty support.
