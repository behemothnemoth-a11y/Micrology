# Claude First-Session Checklist

Use this to keep the first coding session from drifting.

- [ ] New repo initialized
- [ ] README states this is a standalone engine, not a Minecraft mod
- [ ] Rust workspace builds
- [ ] Tests run from repo root
- [ ] Sandbox app opens
- [ ] Free camera works
- [ ] Native `MaterialId`
- [ ] Native volume structure
- [ ] At least 16x16x16 fixture supported
- [ ] Exact surface extractor
- [ ] Deterministic mesh result
- [ ] Solid volume does not emit internal faces
- [ ] Mixed-material boundary stays correct
- [ ] One native fixture rendered
- [ ] Simple versioned save/load
- [ ] Save/reload equality test
- [ ] One runtime edit works
- [ ] Edit triggers local dirty rebuild
- [ ] README contains run/test instructions

Stop and report before broadening scope.
