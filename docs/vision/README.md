# Vision pack

The original project brief, preserved verbatim as it was handed over. These files
are the source of truth for *intent*; the code is the source of truth for what
exists today.

They are kept because `06_FUTURE_ROADMAP.md` exists specifically so the long-term
vision is not lost while early drops stay disciplined. Read them in numeric order.

| file | what it settles |
|------|-----------------|
| `00_START_HERE.md` | what this project is, and what it is not |
| `01_PROJECT_CHARTER.md` | core goals, and non-goals for the first milestone |
| `02_ARCHITECTURE.md` | layer layout, language choice, representation strategy |
| `03_DROP_0001_SCOPE.md` | the deliverable this repository currently implements |
| `04_DESIGN_PRINCIPLES.md` | the ten guardrails, quoted throughout the code |
| `05_ASTRA_MICROBLOCKS_PORTING_NOTES.md` | which proven ideas to carry over, and which not to |
| `06_FUTURE_ROADMAP.md` | phases A–J, none of which are started yet |
| `07_REPO_SKELETON.md` | the suggested crate layout this repo follows |
| `08_CLAUDE_KICKOFF_PROMPT.txt` | the original implementation instruction |
| `09_FIRST_SESSION_CHECKLIST.md` | the first-session checklist, scored in `../drop-0001.md` |

Nothing in here is a specification of current behaviour. Where a vision file and
the code disagree, the code is what runs and `../drop-0001.md` explains the gap.
